# Imágenes del sitio

Subí acá los archivos de imagen que uses en el sitio. Cada imagen se asocia a un “slot” en `src/data/images.ts` (nombre del archivo + texto alternativo + crédito de Unsplash).

**Ejemplo:** el hero de la página de inicio usa la imagen **hero.jpg**.  
→ Poné en esta carpeta el archivo `hero.jpg` y en `src/data/images.ts` ya está configurado el crédito (Geronimo Giqueaux / Unsplash).

Para agregar más imágenes: añadí el archivo en esta carpeta, después decime el nombre del archivo y en qué pantalla va; yo te indico qué id usar y vos me pasás el crédito de Unsplash para cargarlo en `images.ts`.
